# Краткая инструкция: собственный шаблон печатной формы

Откройте **Документы → Конструктор макетов**.

## Создать шаблон с нуля

1. Выберите форму: **ФПУ-26** или **Сохранная расписка**.
2. Выберите ДПО и период. Они нужны только для проверки шаблона на реальных данных.
3. Нажмите **Создать свой макет**. Откроется чистый лист формата A4.
4. Щёлкните нужную ячейку и в блоке **Поля документа** нажмите название поля. Например, «Название ДПО» или «ФИО работника».
5. Оформите лист: измените текст, шрифт, границы, ширину столбцов, высоту строк и объединение ячеек.
6. Для таблицы обязательно разместите поля **Начало строк таблицы**, **Конец строк таблицы** и нужные поля из группы **Строки таблицы**.
7. Нажмите **Предпросмотр Excel** или **Предпросмотр PDF**.
8. Нажмите **Сохранить новую версию**.
9. Если возле версии показаны ошибки, откройте её в редакторе, исправьте и сохраните ещё раз.
10. Когда версия отмечена как **Валидна**, нажмите **Активировать**.

Важно: сохранение никогда не заменяет действующий шаблон. Новый макет начинает использоваться только после активации валидной версии.

## Изменить готовый шаблон

В таблице версий нажмите **Редактор** возле нужной версии. После сохранения появится новая версия, а исходная останется без изменений.

## Загрузить шаблон из Excel

Если макет подготовлен в Excel, выберите файл `.xlsx` в блоке **Или загрузить готовый Excel** и нажмите **Загрузить и проверить**. В файле должны быть те же обязательные поля-маркеры.
