## Важное перед началом

Рабочая ветка сейчас содержит незакоммиченные изменения другой модели, в том числе в
`employee-form.js`, `nav-sections.js` и печатной форме 1.7. Нельзя одновременно
редактировать эти файлы в одном рабочем каталоге. Сначала закончить и зафиксировать
текущую работу либо создать отдельную ветку/worktree для каждого исполнителя.

Не переименовывать таблицы, REST-пути и внутренние поля `subdivision` в `station`:
«Станции» — новое пользовательское название существующего справочника
«Подразделения». Миграция данных для этой правки не нужна.

## Ответ по пункту 4: что такое «БЕ»

**БЕ — бизнес-единица.** В карточке ДПО поле хранит код бизнес-единицы РЖД
(`businessUnitCode`) и используется в реквизитах печатных форм. Само поле пока
оставить. Для понятности подпись можно показывать как **«Код бизнес-единицы (БЕ)»**.

- Физическое переименование таблицы/модели `Subdivision`.

  родительный вариант хранятся отдельно.
