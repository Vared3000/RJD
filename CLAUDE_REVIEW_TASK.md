## 1. Одинаковая сортировка экрана и Excel/PDF

В `server/src/modules/reports/reports.service.js` функция `sortPersonnelListRows()` строит цепочку `region -> dpoName -> fullName`, но ветка для `dpoName` отсутствует. Сейчас `dpoName` попадает в `else` и сравнивается как `fullName`. В результате экспорт по умолчанию фактически сортируется `Регион -> ФИО`, тогда как экран сортируется `Регион -> ДПО -> ФИО`.

Исправить обработку `dpoName`. Добавить интеграционный тест минимум с двумя ДПО в одном регионе и такими ФИО, при которых неправильный порядок будет заметен. Проверить одинаковый порядок API списка работников и выгрузки.

## 2. Корректный статус работника на экране

Фильтр `Статус = Уволен` возвращает нужную выборку, но общий `CatalogPage` выводит в колонке статуса только состояние архива (`archivedAt ? "В архиве" : "Активно"`). Поэтому уволенный, но не архивный работник визуально показывается как активный.

Передавать/вычислять единый статус по правилам ТЗ: `В архиве` -> `Уволен` -> `Активен`, и отображать его в списке работников. Не ломать статусную колонку остальных справочников. Предпочтительно предусмотреть узко настраиваемый renderer/поле для `CatalogPage`, а не встраивать проверку employees внутрь универсального компонента.

Добавить тест либо проверяемую компонентную логику, которая исключает подпись `Активно` для уволенного работника.

## 3. Сортировка по вычисляемому статусу

Проверить будущую дату увольнения. Такой работник имеет статус `Активен`. Текущая SQL-сортировка по `archivedAt` и `terminationDate` может помещать будущую дату отдельно от остальных активных и нарушать группировку статусов. Сортировка ASC/DESC должна опираться именно на три вычисляемых статуса и быть одинаковой на экране и в выгрузке, включая будущую дату увольнения.

Добавить регрессионный тест для активного работника с будущей датой увольнения.

## 4. Активные фильтры в печатной форме

`reportsService.employeesList()` применяет `search`, но не добавляет его в `filtersText`. По ТЗ Excel/PDF должны содержать все активные фильтры. Добавить поисковую строку в описание фильтров и покрыть тестом.
