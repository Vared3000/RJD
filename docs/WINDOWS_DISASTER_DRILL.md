# Испытание полной потери основного ПК

Релиз Р считается принятым только после реального отключения текущего активного ПК. Код не
имитирует физическую потерю и не выставляет статус `accepted` без ручных проверок.

1. На активном ПК создайте контрольный документ и дождитесь ежечасной копии.
2. Запустите **«Испытать потерю основного ПК»**. Скрипт зафиксирует один точный backup и его
   SHA-256 на всех трёх ПК.
3. Физически отключите этот ПК от сети. Не используйте его диск или общую папку.
4. На ПК №2 запустите **«Аварийное восстановление»**. Мастер сам подхватит pending `DrillId` и
   закреплённую копию.
5. После сообщения **«Программа работает»** снова запустите **«Испытать потерю основного ПК»** на ПК №2.
6. Подтвердите вход с двух рабочих мест, контрольные данные и одну печатную форму.

Итоговые JSON и Markdown записываются в `BACKUP_ROOT\drills`. В них есть исходный и новый узел, эпохи,
backup/SHA-256, фактические RPO/RTO, неизменность двух доступных копий и ручные отметки.
